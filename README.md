# Kahve Fincanı Kötü Haber Falcısı

## Resmi Tanıtım

Bu proje, Türkiye Cumhuriyeti Bilim ve Fal Akademisi tarafından onaylanmış (onaylanmamış) tek resmi kahve fincanı okuma algoritmasıdır. Algoritma, fincanın dibindeki lekeleri analiz ederek yalnızca kötü haberler üretir. İyi haber yoktur. İyi haber yalancıdır.

### Nasıl Çalışır?

1. Kahvenizi için.
2. Fincanı ters çevirin.
3. Bu script'i çalıştırın.
4. Hayatınızın mahvolmasını bekleyin.

Kod tamamen bilimseldir. Bilimsel olmayan tek şey sizin umutlarınızdır.

### Kullanım

```bash
python falci.py
```

Sonra size ne sorduklarını anlayacaksınız. Anlamazsanız da sorun yok, zaten kötü haber gelecek.

## Uyarı

Bu falcı asla "her şey güzel olacak" demez. Demesi yasaktır. Eğer derse, kodu bozmuşsunuz demektir.
